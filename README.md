# Projeto Delivery — Banco de Dados

## Sobre o projeto

Projeto acadêmico de modelagem e implementação de banco de dados para um aplicativo de delivery, com o objetivo de organizar informações de clientes, restaurantes, produtos, pedidos, pagamentos e entregas.

O projeto aborda desde a análise do problema e levantamento de requisitos até a modelagem de dados e implementação utilizando SQL.

## Etapas do projeto

- **Etapa 1:** Análise do problema e levantamento de requisitos.
- **Etapa 2:** Modelo conceitual.
- **Etapa 3:** Modelo lógico relacional.
- **Etapa 4:** Normalização do banco de dados.
- **Etapa 5:** Implementação e consultas SQL.

## Modelagem

O modelo contempla entidades como:

- Cliente
- Endereço
- Restaurante
- Entregador
- Cardápio
- Produto
- Pedido
- Item do pedido
- Pagamento
- Entrega
- Status do pedido
- Histórico de status
- Avaliação

## Tecnologias e conceitos

- SQL
- Modelagem conceitual e lógica
- Entidades e relacionamentos
- Chaves primárias (PK)
- Chaves estrangeiras (FK)
- Normalização (1FN, 2FN e 3FN)
- Criação e manipulação de tabelas
- Consultas e funções SQL
